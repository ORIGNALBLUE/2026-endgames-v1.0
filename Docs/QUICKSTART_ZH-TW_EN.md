# Quick Start / 快速開始

1. Run `Launch_Lifeline.cmd`. / 執行 `Launch_Lifeline.cmd`。
2. Choose language and the game folder. / 選語言與遊戲資料夾。
3. Enter measured FPS **before** frame generation. / 填入 FG 前的實測 FPS。
4. Leave Strategy on **Recommended** and click Apply Recommended. / 保持「建議」並按套用。
5. If a game fails, restore the latest backup and export a support bundle. / 若失敗就還原備份並匯出支援包。

Advanced mode is optional. FSR 4.0.2c is not accepted. External FSR 4.0.2 is experimental and manual-only.
