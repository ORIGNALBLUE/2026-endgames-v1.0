# External FSR 4.0.2 slot

Lifeline **does not bundle or download FSR 4.0.2c**.

If you have a legally obtained FSR 4.0.2 candidate, select `amd_fidelityfx_upscaler_dx12.dll` through the Lifeline UI. The manager records version, Authenticode status and SHA256 in diagnostics.

This path is experimental on pre-RDNA3 hardware. If validation or execution fails, use FSR 3.1, XeSS, or DLSS instead.
